Tipy a návody

Snímek celé webové stránky (včetně nezobrazené části)

Postup je určen pro prohlížeče Chrome a Edge a nevyžaduje žádné rozšíření. Snímek pořizuje samotný prohlížeč, lze jej proto použít i u stránek vyžadujících přihlášení (včetně vícefaktorového ověření). Výsledkem je soubor PNG ve složce Stažené soubory (Downloads), nikoli obrázek ve schránce. Postup pro jeho vložení do aplikace ScreenBoard je uveden níže.

Pořízení snímku ve vývojářských nástrojích
  1. Otevřete požadovanou stránku a stiskněte klávesu F12 (případně Ctrl+Shift+I).
  2. Klikněte dovnitř okna vývojářských nástrojů, nikoli do samotné stránky.
  3. Stiskněte Ctrl+Shift+P; otevře se příkazová nabídka (Command Menu). Alternativně zvolte nabídku ⋮ a příkaz „Spustit příkaz“ (Run command).
  4. Zadejte slovo snímek (screenshot).
  5. Vyberte příkaz Zachytit snímek obrazovky s celou velikostí (Capture full size screenshot).
  6. Snímek se uloží jako soubor PNG do složky Stažené soubory (Downloads).

Názvy příkazů odpovídají jazyku vývojářských nástrojů: v české verzi (CZ) platí první uvedený název, v anglické verzi (EN) název v závorce. Obdobné příkazy: „Zachytit snímek obrazovky“ (Capture screenshot) pořídí viditelnou část stránky, „Capture area screenshot“ vybranou oblast a „Capture node screenshot“ vybraný prvek stránky; v české verzi mají obdobně znějící názvy.

Změna jazyka vývojářských nástrojů (CZ ⇄ EN)
  1. V otevřených vývojářských nástrojích stiskněte klávesu F1 (Nastavení / Settings).
  2. Zvolte položku „Předvolby“ (Preferences) a v ní „Jazyk“ (Language).
  3. Vyberte požadovaný jazyk: „čeština“ (Czech) nebo „English“ (angličtina).
  4. Potvrďte opětovné načtení vývojářských nástrojů („Znovu načíst“ / Reload DevTools).

Změna se týká pouze vývojářských nástrojů, nikoli celého prohlížeče.

Vložení snímku do aplikace ScreenBoard

Varianta A – přímo ze souboru

  1. V poli galerie (vpravo v liště záložek) klikněte na ikonu složky .
  2. Vyberte soubor PNG ze složky Stažené soubory. Snímek bude vložen do první volné buňky aktivní nástěnky.

Varianta B – prostřednictvím schránky

  1. Otevřete uložený soubor v libovolném prohlížeči obrázků (například v Malování) a stiskněte Ctrl+A a poté Ctrl+C.
  2. V aplikaci ScreenBoard stiskněte Ctrl+V, případně klikněte na ikonu vložení ze schránky (ne v textovém poli).

Snímek celé stránky do schránky umí zkopírovat také některá rozšíření prohlížeče a v prohlížeči Edge funkce Web Capture (Ctrl+Shift+S); její názvy a tlačítka se v české verzi mohou lišit. Upozornění: Ctrl+Shift+S je zároveň výchozí zkratka aplikace ScreenBoard pro snímek celého monitoru; jednu z nich změňte v části „Snímání“.

Řešení potíží
  • Zkratka otevře jiné okno: v prohlížeči Edge otevře Ctrl+Shift+P stisknutá mimo vývojářské nástroje okno InPrivate. Nejprve klikněte dovnitř vývojářských nástrojů.
  • Příkazová nabídka příkaz nenalezne: příčinou bývá jazyk nástrojů. Zadejte slovo „snímek“ (screenshot), případně jazyk nástrojů změňte (viz výše).
  • Chybí obsah načítaný až při posouvání stránky: před pořízením snímku stránku prolistujte kolečkem myši dolů a zpět nahoru.
  • Snímek je prázdný nebo oříznutý u velmi dlouhé stránky: grafika má limit přibližně 16 000 px na výšku. Snímejte stránku po částech, případně použijte příkaz „Capture area screenshot“.
  • Příkaz není k dispozici: na stránkách chrome:// a v prohlížeči, kde správce vývojářské nástroje zakázal, příkaz nefunguje.

Screenshot of a whole web page (including the part not shown)

This procedure is intended for Chrome and Edge and requires no extension. The screenshot is taken by the browser itself, so it also works for pages that require a login (including multi-factor authentication). The result is a PNG file in the Downloads folder, not an image in the clipboard. How to add it to ScreenBoard is described below.

Taking the screenshot in the developer tools
  1. Open the required page and press F12 (or Ctrl+Shift+I).
  2. Click inside the developer tools window, not into the page itself.
  3. Press Ctrl+Shift+P; the Command Menu opens. Alternatively, choose the ⋮ menu and the command “Run command” (Czech: “Spustit příkaz”).
  4. Type screenshot (Czech: snímek).
  5. Select Capture full size screenshot (Czech: Zachytit snímek obrazovky s celou velikostí).
  6. The screenshot is saved as a PNG file in the Downloads folder.

The command names follow the language of the developer tools: the English (EN) name applies to the English version, the Czech (CZ) name given in brackets to the Czech version. Similar commands: “Capture screenshot” captures the visible part of the page, “Capture area screenshot” a selected area and “Capture node screenshot” a selected page element; they have similarly worded names in the Czech version.

Changing the language of the developer tools (EN ⇄ CZ)
  1. With the developer tools open, press F1 (Settings; Czech: Nastavení).
  2. Choose “Preferences” (Czech: Předvolby) and then “Language” (Czech: Jazyk).
  3. Select the required language: “English” or “čeština” (Czech).
  4. Confirm reloading the developer tools (“Reload DevTools”).

The change applies to the developer tools only, not to the whole browser.

Adding the screenshot to ScreenBoard

Option A – directly from the file

  1. In the gallery field (right end of the tab bar) click the folder icon .
  2. Select the PNG file from the Downloads folder. The screenshot is placed in the first free cell of the active board.

Option B – via the clipboard

  1. Open the saved file in any image viewer (for example Paint) and press Ctrl+A and then Ctrl+C.
  2. In ScreenBoard press Ctrl+V, or click the paste icon (not inside a text field).

Some browser extensions can also copy a full-page screenshot to the clipboard, and Edge offers the Web Capture function (Ctrl+Shift+S); its names and buttons may differ between language versions. Please note: Ctrl+Shift+S is also ScreenBoard’s default shortcut for a full-monitor capture; change one of them in the “Capturing” section.

Troubleshooting
  • The shortcut opens another window: in Edge, Ctrl+Shift+P pressed outside the developer tools opens an InPrivate window. First click inside the developer tools.
  • The Command Menu does not find the command: the cause is usually the language of the tools. Type “screenshot” (Czech: “snímek”) or change the language of the tools (see above).
  • Content loaded only while scrolling is missing: before taking the screenshot, scroll the page down with the mouse wheel and back to the top.
  • The screenshot is blank or cut off on a very long page: the graphics has a limit of about 16,000 px in height. Capture the page in parts, or use the “Capture area screenshot” command.
  • The command is not available: it does not work on chrome:// pages, nor in a browser where an administrator has disabled the developer tools.
