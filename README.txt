ScreenBoard v0.8.0
Spusteni: npm install, potom npm start
Ctrl+Shift+S = cely monitor, Ctrl+Shift+A = jen oblast (vyrez); zkratky jdou zmenit v Nastaveni.
Data (snimky, nastenky, nastaveni, log.txt) jsou ve slozce userData/data (Windows: %APPDATA%/ScreenBoard/data).
Pri prvnim spusteni se data prevezmou ze stare slozky aplikace PrintScreen (%APPDATA%/printscreen/data).
